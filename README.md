# F1 2020 Big Data Analytics Project

This project analyzes **Formula 1 2020 race data** using **Apache Hadoop and MapReduce**.

## Technologies Used

- Apache Hadoop 3.3.6
- HDFS
- MapReduce
- Python
- Docker
- F1 2020 Dataset

## Dataset

The project uses F1 2020 race data containing:

- Participant Data
- Race Time Data
- Session Data
- Telemetry Data
